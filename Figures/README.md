
This directory contains the figures generated from the Python-based numerical simulations of the Fourier Optics project.

The figures visualize the simulated diffraction and propagation patterns for the optical systems studied in the project. Depending on the problem, the results are presented using different representations of the intensity distribution, including:

* 3D plots of the optical intensity
* 2D linear-scale intensity maps
* 2D logarithmic-scale normalized intensity maps

The figures are organized according to the corresponding project phases and simulation problems.
